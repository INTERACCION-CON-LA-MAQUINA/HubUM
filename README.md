# HubUM

# Propósito del proyecto
El objetivo principal de este proyecto es mantener informados a los estudiantes acerca de la disponibilidad de salas de biblioteca y de laboratorio, permitiéndoles optimizar su tiempo de gestión y evitar viajes innecesarios en el campus cuando los espacios se encuentran ocupados.
